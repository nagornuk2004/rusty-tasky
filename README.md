# Rusty Tasky

A task planner app. Built with Relm4 and GTK-rs.

This is just for me to learn those frameworks. Don't use this. This is not a good app. It's very crude.

But if you really want to, clone the repo and build it with cargo:
```
git clone https://github.com/nagornuk2004/rusty-tasky.git
cd rusty-tasky
cargo run
```
